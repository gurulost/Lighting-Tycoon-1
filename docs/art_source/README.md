# Art Sources

This folder stores **high‑resolution source images** for characters.
Use these as the master inputs when re‑exporting game‑ready sizes.

## Characters
- `tina/` (multiple expressions)
- `mentor/`
- `baron/`

## Export sizes used in the game
- 128×128 (dialogue chips)
- 256×256 (glossary / modal usage)
- 512×512 (hero / future use)

If you add new art, keep the sources here and export optimized sizes into
`assets/images/<character>/`.
