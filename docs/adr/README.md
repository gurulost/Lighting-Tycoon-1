# Architecture Decision Records (ADR)

Use ADRs to record significant decisions that affect the architecture, tooling, or long-term direction of the project.

## How to Add an ADR

1. Copy the template below into a new file.
2. Name the file with the next number: `0002-brief-title.md`.
3. Fill in the context, decision, and consequences.

## ADR Template

```
# [NUMBER] [Title]

Date: YYYY-MM-DD

## Context

## Decision

## Consequences
```
